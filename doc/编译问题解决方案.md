# Windows 编译问题解决方案

## 问题 1: sqlite3 下载失败

错误信息：`downloading 'https://sqlite.org/2026/sqlite-autoconf-3520000.tar.gz' failed`

### 解决方案

**方案 A：配置正确的代理**
```bash
# 设置正确的代理（确保代理可以访问 sqlite.org）
set https_proxy=http://你的代理:端口
set http_proxy=http://你的代理:端口
flutter clean && flutter run -d windows
```

**方案 B：临时关闭代理**
```bash
set https_proxy=
set http_proxy=
flutter clean && flutter run -d windows
```

**方案 C：手动下载 SQLite**（已配置）

已在 `windows/sqlite3/` 目录配置了本地 SQLite 源码。

## 问题 2: just_audio C4819 警告

已在 `windows/CMakeLists.txt` 中添加 `/wd"4819"` 解决。

## 问题 3: just_audio sourceNotSupported

错误信息：`PlatformException(sourceNotSupported, null, null, null)`

### 原因
- 文件路径包含中文字符可能导致问题
- just_audio_windows 对某些文件格式支持有限

### 解决方案
1. 使用简单的英文文件名
2. 确保文件是标准的 MP3/WAV 格式
